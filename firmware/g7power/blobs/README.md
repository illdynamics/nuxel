# firmware/g7power/blobs/

Placeholder directory for firmware blobs collected from the physical
Motorola Moto G7 Power (ocean).

**Nothing is stored here yet.** All blobs are UNKNOWN/TBD until the operator
runs the Phase 0 inventory (see phones/g7power/g7power-requirements.md and
docs/hardware-ids.md) and fills real filenames + sha256 checksums into
`firmware/g7power/manifest.yml`.

Do NOT copy blobs from any other device target into this directory.
