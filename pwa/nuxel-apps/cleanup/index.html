      What this tool will never do

      • It never writes to a raw partition or block device. The beta mission forbids all direct writes.
      • It never removes user documents, pictures, music, downloads or the Trash.
      • It never removes package-manager state (the RPM database or /var/lib/dnf).
      • It never follows symlinks out of an allowlisted directory, and it only deletes regular files.
      • It refuses to run at all when the Nuxel host is unreachable, instead of reporting a delete it did not do.
