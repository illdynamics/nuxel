Connection

On the Nuxel host, run python3 services/nuxel-penguru/tools/mint-android-token.py as root, then paste the printed token here. The token is bound to PenGuru and expires; re-mint it if model controls report launcher_token_required.

Voice · local speech

Install the optional Voice tiny.en package under SonarBird in Model library. Audio is sent only to your PenGuru host on the configured link and is discarded after recognition. MiniLM routes text; Whisper handles speech.

Microphone closed

Foreground beta: listening stops when you hide the app or turn PenGuru off. Wake detection uses local transcription, not a low-power background wake-word model. Review the transcript and press Send; speech never authorizes actions.

Privacy

Prompts and answers are not saved to disk. Responses remain in memory for this session. No cloud inference or telemetry. Turning PenGuru off stops its services, downloads and workers.

Approvals & code

Privileged actions and generated-code execution are unavailable until their isolation and approval gates pass on the host. You can review and export responses.
