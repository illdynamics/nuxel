external navigation: blocked start page

Local Nuxel pages

Nuxel Browser opens pages served by this device. It never becomes a search engine and it performs no background requests; external navigation stays blocked until you explicitly enable it in the menu.

Reading list

    External navigation is blocked

    Nuxel ships offline-first: no external service is contacted by default. Open the menu and enable “Allow external navigation” if you really want to load this URL through WebKitGTK. Nothing is fetched until you do.

    Nuxel Browser

    When on, pages fetched from the network can be loaded in the view. The Nuxel policy for this app is network: opt-in; the default is off.
