Keyboard

Legacy text-input v1 compatibility

Electron/Chromium 122 applications such as Caprine 2.61 only speak zwp_text_input_v1, which modern Phoc/wlroots no longer exposes. Enabling this opt-in shim lets those apps raise the same Stevia keyboard that GTK apps and Nuxel PWAs already use through zwp_text_input_v3. The normal keyboard and v3 path are unchanged.

Applies to newly launched apps immediately. If an Electron app is already running, close and reopen it so it can see the new protocol.

Boot diagnostics

Three independent controls, one durable document (/etc/nuxel/boot/verbose-boot.json). All three apply from the next boot, are written by nuxelctl verbose-boot … and by this panel through the same file, and are never overwritten by a package/rootfs update. Precedence for the animation is off > short > verbose boot > standard; the verbosity level only picks how much the log says, never whether it is shown.
