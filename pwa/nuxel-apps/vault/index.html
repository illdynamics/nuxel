Create your Nuxel Vault keyring

      
Nuxel Vault stores items in the operating system's Secret Service
        (GNOME Keyring). The keyring encrypts them at rest; the master password is
        never stored by Nuxel and cannot be recovered if you lose it.

      
    
        
  • The master password protects the whole Nuxel keyring on this phone.
    • 
        
  • Losing it and every encrypted backup means the data is unrecoverable.
    • 
        
  • There is no cloud escrow, no hidden recovery key and no network sync.
    •

What linking means

        
Linking stores the Authenticator vault passphrase in this OS keyring
          only after you opt in inside Authenticator. It lets Authenticator unlock automatically
          only while the Nuxel keyring is unlocked. Anyone or any process that can use
          the unlocked keyring with Authenticator's granted access may be able to unlock those
          TOTP secrets. Keep the keyring protected.

        
Vault never reads the Authenticator credential. Link, rotate or remove it
          in Authenticator → Security. Removing it never deletes your TOTP accounts.

      

    


    

      

        
Encrypted export

        
The archive is AES-256-GCM under a PBKDF2-SHA-256 key derived from a
          separate export passphrase. There is no plaintext export button.

Change master password

        
GNOME Keyring does not expose a safe standard Secret Service API to change
          the collection master password. Nuxel will not use a private/unsupported keyring
          interface. To rotate it, create a new keyring after exporting an encrypted backup,
          or use the provider's own desktop tooling. This build reports the limitation instead
          of pretending the password changed.

      

      

        
Reset Nuxel Vault items

        
Deletes only items owned by org.nuxel.Vault. It does not delete
          the Authenticator credential, the Authenticator TOTP vault, or unrelated keyring items.
