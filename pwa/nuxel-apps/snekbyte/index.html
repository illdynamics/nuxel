How the port is verified

SnekByte is a port of the original Python/pygame game. Fidelity is not asserted by eye: the real upstream modules are executed by tools/s10plus/a33/snekbyte/gen-parity-fixtures.py over scripted input, and the JavaScript engine in js/snek-engine.js must reproduce that recording tick for tick.

Everything (provenance + parity + shell)python3 tools/s10plus/a33/snekbyte/tests/test-snek-parity.py

Result recorded in tools/s10plus/a33/snekbyte/fixtures/parity.json: 3 scenarios, 41 ticks, wall + self + WoNQ-poop endings, every field identical.
