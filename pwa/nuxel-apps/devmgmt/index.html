Raw reads (read-only)

These are the exact bytes the tool parsed, one section per path. Nothing on this page writes to the filesystem.

Read-only by default

DevMgmt performs no privileged action at all. Every path below is opened for reading (system.read with mode: read-only) and refusals are shown as refusals.

Actions that would need root

These are listed so the boundary is explicit. They are not implemented here, and each one is labelled with what it would actually change:

  • Write a sysfs tunable (for example a thermal trip point or a USB gadget attribute) — needs CAP_SYS_ADMIN or a udev rule; changes live kernel state until reboot.
  • Rebind a driver (/sys/bus/*/drivers/…/{unbind,bind}) — needs CAP_SYS_ADMIN; can detach the touchscreen or the panel and is not recoverable from this UI.
  • Set the RTC or the clock — needs CAP_SYS_TIME (Root & Sudo shows the real mechanism).
  • Change CPU governor / frequency — needs write access to /sys/devices/system/cpu/cpufreq; can thermal-throttle or overheat the device.
  • Install staged files — always through NuxTore with a verified signature, never by hand here.

Root & Sudo is the honest place to look at the privilege mechanism; it also states plainly that root compromise is out of scope for any claim this build makes.
