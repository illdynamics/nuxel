# Use and distribution notices

The original Python utilities and Markdown content in this pack are authored for this Nuxel research handoff. External programs, papers, proprietary vendor ELFs, firmware and kernel sources are **not** copied into this pack. Follow each project's license and Samsung firmware restrictions independently.

The captured `AST_POWERON` and `DELETE_ALL_VIS` samples are user-supplied Stage 05 diagnostic examples and are reproduced only to create offline test vectors. No SIM/IMEI/ICCID/IMSI, private EFS/NV data, passwords or modem firmware is included.

BaseMirror is referenced by URL, not bundled. Its project includes research components for automated testing and attack discovery which are **out of scope** for working on Nuxel's live cellular hardware. This pack uses only read-only host-based analysis concepts.
