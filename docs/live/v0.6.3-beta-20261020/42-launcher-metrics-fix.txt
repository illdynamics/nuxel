# A44 launcher/nav/metrics fix - live S10+ verification
# 2026-10-20 ~15:16 CEST (13:16 UTC), userspace only

## Fixes

- Shortcut dock no longer paints its own copy of nuxel-bottom-bar artwork.
  The four dock shortcuts (Phone, Messages, Settings, Terminal) are visible.
- Navigation artwork is confined to the Back/Home/Recents strip (62 CSS px)
  instead of painting a 120 px layer upward over the dock.
- Home/penguin button always resets to desktop 1, scroll top, no drawer/edit
  overlay, and long-press Home also returns Home instead of opening Settings.
- Home launcher pinch/double-tap/Ctrl-wheel zoom blocked.
- CPU/MEM/GPU/VRAM poller was frozen by WebKit serving a cached metrics 200
  after the socket-activated collector exited. Every sample is now query
  cache-busted; nuxel-metricsd accepts /metrics?t=... and OPTIONS.
- VRAM now reports Mali allocation bytes and shared-RAM budget instead of N/A.
