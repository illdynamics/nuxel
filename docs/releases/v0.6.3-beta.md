# Nuxel v0.6.3-beta — candidate and known acceptance blockers

This is a **source / CI candidate**, not a hardware-certified daily driver.

## Implemented in this patch

- Single NetworkManager Wi-Fi control pathway shared with the launcher; a new
  Wi-Fi Settings tab supports real NM state, scanning, radio control, WPA2/WPA3
  connection initiation and disconnection. Requires working kernel Wi-Fi,
  firmware, D-Bus authority and a live owner association test.
- Corrected dock artwork stacking and retained independent BG1/BG2 selection,
  plus gesture improvements and suppression of Home-only pinch zoom.
- S10+ release build remains the source-built A34 boot + Fedora ARM64 rootfs;
  GitHub Actions release source is pinned to a merged commit or tag.
- Existing browser, file explorer, telemetry and diagnostics retained.

## Hardware blockers / pending tests from `final.md`

| Surface | Status | Required real-world evidence |
|---|---|---|
| Dock assets and transitions | Source patched, device unverified | Visual phone screenshot; JPG/PNG HTTP + hash checks |
| CPU/RAM/GPU/GPU-memory meters | Existing source, hardware unverified | Real /proc and Mali/sysfs data; no fake VRAM |
| Wi-Fi | Bridge + UI source added, device unverified | NM Wi-Fi device, AP scan, WPA association, DHCP, DNS, HTTPS |
| Browser | Existing app, external site limitations | True top-level WebKit TLS page load + navigation |
| File Explorer + ZIP | Existing app, integration unverified | Real touch file ops in home dir + archive safety |
| Audio speaker + cue | Blocked pending on-device evidence | ALSA card, DAPM route, firmware, audible owner confirmation |
| Bluetooth | Existing backend needs owner test | Real controller, pair and audio/keyboard profile |
| NFC | Driver availability unknown | NCI device, physical NDEF tag |
| GPS + Maps | Hardware fix unverified | GNSS fix with timestamp/accuracy; OSM tiles separately |
| Camera | Samsung ISP/driver may be unsupported | Actual front/rear captured video frames |
| Button chords and flashlight | Hardware unverified | input-event trace, actual torch/screenshot |
| Status/Quick Settings | UI mostly present, hardware unverified | Accurate real states for all controls |
| S10+ boot/release | CI not executed in sandbox | Green remote CI job + downloaded artifact + device boot |

`final.md` is the complete requirements specification; this table is an
honest delta, **not a claim that all phases are fixed**.

## Release route

1. Push a feature branch and open a PR. Never push protected `main` directly.
2. Merge PR after review. The `push main` workflow checks VERSION and runs the
   S10+ image builder. After a successful build it pushes an annotated version
   tag and creates a GitHub prerelease (requires Actions write permission to tags).
3. For a manual tag release instead, only after the versioned commit exists on
   main, create `git tag -a v0.6.3-beta -m "Nuxel v0.6.3-beta"`, then
   `git push origin refs/tags/v0.6.3-beta`; tag push triggers the same workflow.
4. Verify `gh run list --workflow release.yml`, `gh release view v0.6.3-beta`,
   and download/`sha256sum -c` the S10+ archive.

Never flash the image during a live userspace deployment. Keep the USB console
and known-good rollback available.
