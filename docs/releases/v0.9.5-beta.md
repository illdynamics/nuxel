# Nuxel v0.9.5-beta — SMS final acceptance, SIM import/sync and VoLTE roadmap

Release source: `main` (merged PR `feature/sms34.5-sim-import-checked`).

## Highlights

- **Messages** — complete conversation threads, an explicit All-messages view,
  and the same list inside each thread, so every stored logical SMS is
  reachable. "Import SIM" copies SIM-mirror messages and contact names into the
  local store additively; "Sync" re-runs that and copies local messages the
  mirror lacks. Nothing is ever deleted and the physical SIM is never written.
- **Contacts** — Nuxel design parity (navy ground, rounded cards, cyan accent,
  40 px targets), "Back up all", and a corrected model loader.
- **nuxel-phone-data** — fixed a JSON-reader defect that made every store
  containing an empty string (`"email": ""`) reload as empty; added merge /
  SIM-import helpers and their offline tests (90 checks).
- **Notifications / SMS / IMS** — the Round 34.5 hardening described in
  `sms34.5.md` is what runs on the handset.
- **VoLTE** — readiness audit and roadmap in `volte-report.md`.

## Known constraint of this release tag

`main` at this commit does not contain the S5000AP radio sources
(`tools/s10plus/s5000ap-05/*`) or the notifications-hub revision that the
handset runs; those live on the development branch and in the deployed
binaries. The GitHub Release artifacts are built from `main`. Reprovisioning a
phone from this release image alone therefore needs the deployed subsystem
artifacts restored from the rollback copies listed in `sms34.5.md` §13, or a
follow-up merge of the S5000AP sources into `main`.
