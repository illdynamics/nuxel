## S10+ live evidence (2026-10-28)

From [`docs/s10plus-live-fixes-20261028.md`](../s10plus-live-fixes-20261028.md):

- **Bootloop fixed.** `abox_is_calliope_incompatible()` no longer reads ABOX
  SRAM from the boot-done hard IRQ; the patched boot image stayed up for more
  than 11 minutes with no ABOX panic.
- **Bluetooth fixed.** HCIUART/H4 is compiled in and `btattach` brings up
  `/dev/ttySAC1`; `hci0` registers, the controller powers on, and a 12-second
  scan discovered a peer.
- **Audio playback works via RDMA1.** RDMA0 does not advance `hw_ptr`; the
  `nuxel-audio-route.service` route and `/etc/asound.conf` default to RDMA1,
  where `aplay -D default` returns 0 with an advancing pointer.
- **GPS remains honestly blocked.** The BCM4773 hardware responds on SPI, but
  the Broadcom BBD/LHD protocol needs the vendor `gpsd`/Android bionic
  userspace, which is not present. The status stays `BLOCKED_FIRMWARE`; no
  position fix is fabricated.

## Verification

The checked-in release gate is `tools/beta/run-all-tests.sh`. The final
v0.7.2-beta run and its exact pass/fail/skip counts are recorded in the merged
PR and GitHub Actions run. Hardware claims above come from the physical S10+
receipt; all other UI work is offline/unit tested and remains subject to owner
acceptance where touch, microphones, haptics feel or a host laptop is required.

## Remaining blockers

- GNSS: vendor BBD/LHD userspace missing (`BLOCKED_FIRMWARE`).
- HDMI/DRM: `CONFIG_DRM` and a Type-C DP Alt Mode stack are absent.
- Camera backend: explicitly deferred; the UI/navigation path is present.
- File transfer: the implementation reports the genuine transport state; a
  laptop-side mount/access remains a host verification step when hardware is
  available.
- Owner acceptance remains open for physical touch-driven app flows, keyboard
  feel, microphone/WAV capture and the complete preload-cinema boot sequence.

## Rollback

- Userspace: restore the timestamped `.nuxel-rollback.*` copies written by the
  live deploy, then restart the affected Nuxel services.
- Kernel: flash the previously proven BOOT image; the ABOX/Bluetooth patch is
  tracked at `kernel/s10plus/patches/0004-nuxel-abox-boot-done-and-bt-hciuart.patch`.
- zsh: follow `services/nuxel-zsh/README.md` (the installer never changes a
  user's shell unless `--set-shell` is requested).
