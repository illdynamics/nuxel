# Nuxel v0.7.3-beta — PWNAGE-37000/38000 boot, Wi-Fi, audio and exact image parity

**Released:** 2026-10-30
**Device under test:** Samsung Galaxy S10+ SM-G975F (`beyond2lte`, Exynos 9820)
**Kernel:** Samsung-derived Linux 4.14.253 with the Nuxel ABOX/Bluetooth patch
**Userspace:** Fedora 43 aarch64
**Release transport:** merged PR to `main` → GitHub Actions builds the exact
merge commit, creates the annotated `v0.7.3-beta` tag and publishes the release.

## What shipped

| Area | Result |
|---|---|
| PWNAGE-37000 — Butterscotch | Cold boot 1 min 22.5 s → 58.9 s; `multi-user.target` 1 min 18.1 s → 17.5 s. ABOX reload no longer blocks the UI target, Wayland stops in 8 s instead of ~46 s, and the Wi-Fi boot bridge no longer waits behind autoconnect. An owner-disabled radio stays disabled. |
| PWNAGE-38000 — audio | The bridge, sound cue and Settings UI share the real PipeWire default sink; the S10+ static sink and graph clock run at 48 kHz because RDMA1 returns EIO with a stalled `hw_ptr` at 44.1 kHz. Audio Settings has a real **Test Audio** action with an honest `audible=unverified` result. |
| PWNAGE-38000 — ABOX reload | `nuxel-abox-firmware-reload.service` cycles ABOX runtime PM with bounded, verified attempts so the Calliope core firmware is loaded before the boot cue. |
| PWNAGE-38000 — first light | `boot/initramfs/init.sh` never paints the legacy A16 diagnostic frame when the first-light asset is absent; `tools/s10plus/a27/repack-splashfix.sh` packs frame 0 of the real animation back into the ramdisk. |
| PWNAGE-34000 — connection modes | Lockscreen console-transport/file-transfer indicators, the Charging/File Transfer selector and the safe USB-mode state machine ship in the launcher and bridge sources. |
| Exact phone capture | `release/s10plus/` was refreshed from the live handset on 2026-10-30: complete BOOT partition `6e998acf…` (57,671,680 bytes) and a 4,238-entry userspace inventory. |
| Version lockstep | `VERSION`, device `APKBUILD`s, launcher/bridge manifests, bridge/notification/portal services, systemd pins, shell apps, OTA/VM tooling and documentation all move to `v0.7.3-beta`. |
| Launcher cache | `v56-v073-release`, replacing the live `v55-fix38-preload-lifecycle` namespace. |

## Remaining blockers

- GNSS: vendor BBD/LHD userspace missing (`BLOCKED_FIRMWARE`).
- HDMI/DRM: `CONFIG_DRM` and a Type-C DP Alt Mode stack are absent.
- Camera backend: explicitly deferred; the UI/navigation path is present.
- File transfer: the implementation reports the genuine transport state; a
  laptop-side mount/access remains a host verification step.
- Owner acceptance remains open for physical touch-driven app flows, keyboard
  feel, audible speaker/headphone output, microphone/WAV capture and the full
  preload-cinema sequence.

## Rollback

- Userspace: restore the timestamped `.nuxel-rollback.*` copies written by the
  live deploy, then restart the affected Nuxel services.
- Boot: flash the previous BOOT partition backup taken before the
  PWNAGE-38000 splash fix.
- Systemd: disable `nuxel-abox-firmware-reload.service` and
  `nuxel-audio-route.timer`, then `systemctl daemon-reload`.
