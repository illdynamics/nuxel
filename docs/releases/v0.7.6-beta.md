# Nuxel v0.7.6-beta — Nuxel Doom, immersive chrome, NuXtore install/remove

**Release date:** 2026-11-04  
**Canonical version:** [`VERSION`](../../VERSION) = `v0.7.6-beta`  
**Application ID:** `org.nuxel.Doom`

## Headline

Nuxel now has its own Doom. **Nuxel Doom** is an original, offline-first,
touch-first shooter with three sectors, a custom 320×180 raycasting engine, a
two-thumb multitouch HUD, sound, optional haptics, pause/resume and local saves.
It is a signed NuXtore package: install it from **NuXtore → Available**, use it
from Nuxel Home, and remove it from **NuXtore → Installed**.

The same release makes app chrome behave like a handheld:

- triple buttons are hidden in every foreground PWA app;
- a bottom-edge swipe reveals Back/Home/Recents;
- real fullscreen apps hide the top bar; a top-edge pull reveals it;
- Nuxel Home and the lockscreen keep their normal chrome.

## Added

- `org.nuxel.Doom` PWA under `pwa/nuxel-apps/doom/`.
- Original raycasting engine, three campaign sectors, enemies, doors, pickups,
  weapons and sector transitions.
- Multitouch movement stick, right-side aim surface, fire/use/weapon/run/menu,
  adjustable sensitivity, inverted look and left-handed mode.
- Pause, restart, return-to-campaign and exit flows.
- Offline service worker and persistent settings/progress.
- Dedicated Nuxel Doom application icon (`icons/icon.svg` plus PNG sizes).
- NuXtore catalogue entry, signed bundle and SHA-256-pinned file list.
- Immersive chrome controller (`pwa/nuxel-home/js/immersive.js`).
- Tests:
  - `pwa/nuxel-apps/doom/tests/test-doom.js` — 31 passed;
  - `pwa/nuxel-home/tests/test-immersive-chrome.js` — 21 passed.
- Documentation: `docs/games/doom.md`, `doom-touch-controls.md`,
  `doom-troubleshooting.md`, this release note.

## Changed

- Nuxel Home hides PWA navigation chrome while an app is foreground and
  restores it on Home/background.
- The native nav dock follows the public `setNavVisible` contract.
- NuxTore-installed dynamic apps disappear from Home when unregistered; static
  built-in apps are never removed by a registry refresh.
- App registry revision 13 records the catalogue-only Doom payload.
- Version lockstep bumped to `v0.7.6-beta` across VERSION, device APKBUILDs,
  shell/launcher/build tooling, bridge/portal/notifications, PWA manifests,
  OTA and VM snapshot tooling.

## Fixed

- Doom never opens the system keyboard: the shell has no text inputs and
  dismisses the OSK on start, focus, resume and exit.
- Fullscreen exit releases all touch states and restores the previous
  orientation.
- The top bar and triple buttons are always recoverable by edge gesture except
  on the launcher and lockscreen.

## Install / remove

```sh
# UI: NuXtore -> Available -> Nuxel Doom -> Install
# UI: NuXtore -> Installed -> Nuxel Doom -> Remove

# Offline verification from a checkout:
python3 pwa/nuxel-apps/nuxtore/tools/nuxtore-verify.py --require-signature --confirm-unsigned org.example.UnsignedDemo
```

## Notes and limits

Nuxel Doom is an original Nuxel game. It does not bundle DOOM WAD files or
commercial DOOM artwork. The **Classic Engine** button is an optional shortcut
to an installed Crispy Doom and is not required for Nuxel Doom to play.

Hardware acceptance of the touched navigation gesture and the new Doom package
still needs an owner-run handset pass. Offline verifiers prove the registry,
catalogue, signatures, file digests and source contracts; they do not prove a
physical touch panel or speaker route.
