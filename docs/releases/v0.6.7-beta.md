# Nuxel v0.6.7-beta — green release gate + transactional Live Console deploy

This is a **beta source/CI release**. A green GitHub Release proves the declared
sources built, verified and packaged from the merged `main` commit; it is not a
statement that every hardware surface has been accepted on the phone.

## Fixed in this release

- **The release gate that failed v0.6.6-beta is fixed.** The v0.6.6-beta
  `main` run went red in `tools/s10plus/a45/test-lockscreen-indicators.py`:
  Ubuntu's GCC rejects `snprintf` paths with `-Werror=format-truncation` unless
  every destination is large enough for the worst case. The indicator path
  buffers in **both** native host sources (`tools/s10plus/a33/nuxel-pwa-host.c`
  and `tools/s10plus/a45/nuxel-pwa-host.c`) are now sized for the root, a
  255-byte dirent and the filename suffix, and the `ind_pid_holds_tty()` result
  is checked before use. Both copies compile clean with GCC 13 under
  `-Wall -Wextra -Werror`, which is the same compile the workflow runs.
- **A77 USB-detach truth.** After a real cable pull the cyan PC penguin and the
  amber Live Console penguin clear. The measured detach log shows this kernel
  leaves `typec/port0/data_role` and the UDC `state` stale at
  `host [device]` / `configured`; A77 adds two independent detach signals to
  both truth providers — a non-connected UDC `current_speed` (`UNKNOWN`) and
  wired VBUS `online=0`. Wireless charging is excluded; absent signals stay
  neutral. `live_console.active` follows the corrected data link and the
  console daemon is never killed to hide the icon.
- **Transactional Live Console deploys.** `declared_reload` and
  `systemctl restart` run once per deploy group instead of once per file. A
  failed group restores its files and re-applies the coalesced activation plan.
  Large payloads use an acknowledged block transfer with bounded retry/rewind
  and fall back to the proven per-frame path. Offline coverage:
  `tools/beta/live/tests/test_live_reload_and_transport.py`; protocol notes:
  `docs/beta-finalization/live/TRANSACTION-RELOAD-AND-BLOCK-TRANSPORT.md`.
- **Release visibility.** The workflow publishes this beta as GitHub's
  **Latest** release (`--latest`), so the repository sidebar shows the newest
  version. The tag and title keep the `-beta` suffix.
- **Whole-repo lockstep bump to `v0.6.7-beta`** across `VERSION`, device
  `APKBUILD`s, PWA/bridge manifests, services, systemd environment pins, shell
  apps, OTA/VM tooling and docs.
- **Launcher cache `v46-a77-usb-detach`** because `status-bar.js` (the shipped
  version marker) and the service worker both moved.

## Release contents

The workflow builds the S10+ BOOT image and Fedora 43 ARM64 phone userspace
from the exact merged commit, runs the source/regression gates, and publishes:

- `nuxel-v0.6.7-beta-s10plus.tar.gz` — CI-built image set from this commit;
- `nuxel-installed-s10plus-boot.img.gz` — the byte-exact BOOT image installed
  on the owner's handset (unchanged by this userspace-only release);
- `nuxel-installed-s10plus-userspace-files.txt.gz` — SHA-256 inventory of the
  installed userspace (refreshed from the phone after the A77 deployment);
- `INSTALLED-IMAGES.json`, `SHA256SUMS.txt` and `RELEASE-NOTES.md`.
