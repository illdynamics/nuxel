# Nuxel v0.9.1-beta — candidate (source patch, device acceptance pending)

This version integrates a single shared Beak configuration for PenGuru Squad and Nuxel Settings, staging-only model downloads, explicit ARM64 ASR/TTS runtime gates, and a safe foreground voice workflow. The existing ChatBird and CodeBird GGUF models continue to use llama.cpp.

**Host-verified gates:** Python syntax, JS syntax, PenGuru security/routing/model tests, Beak configuration tests, and PWA source wiring. This is NOT proof of real voice recognition, full-duplex talkback, or battery acceptance on the S10+.

**Still pending on the device:** Qwen GGUF runtime support, model hash/owner signing, compatible ARM64 `qwen3-asr-cli`, Piper voice + binary, optional Cactus runtime for Needle/Whistle, native RNNoise and Silero VAD, wake accuracy, permissions and thermal profiling. Continuous *background* listening is not shipped; the foreground loop requires user opt-in.

**Release integrity:** The GitHub workflow checks out the merged main SHA and builds versioned images, and only publishes after its physical installed-image provenance gate passes. Merely merging a feature branch does not imply a finished GitHub release; owner should inspect the resulting run later if desired.

See `flash.md` and `PENGURU_AGENT_HANDOFF_V091.md` for safe deployment and acceptance.

Final hardening also rejects non-boolean power-control requests, prevents invalid persisted engine-override state from crashing service startup, and closes a microphone capture session when the OS revokes its audio track. These changes remain host-tested only.
