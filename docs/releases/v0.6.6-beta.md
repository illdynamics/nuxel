# Nuxel v0.6.6-beta — USB detach truth + release visibility

This is a **beta source/CI release**. A green GitHub Release proves the declared
sources built, verified and packaged from the merged `main` commit; it is not a
statement that every hardware surface has been accepted on the phone.

## Fixed in this release

- **Ghost lockscreen icons after USB disconnect.** The cyan PC penguin and the
  amber Live Console penguin now clear as soon as the cable is pulled. Root
  cause: on this S10+ kernel (`4.14.253`) both `typec/port0/data_role` and the
  UDC `state` remain `host [device]` / `configured` after a real unplug, so the
  A73/A74 Type-C veto could never fire. A77 adds two independent, safe detach
  signals to both truth providers — a non-connected UDC `current_speed`
  (`UNKNOWN`) and wired VBUS `online=0` — while keeping absent signals neutral.
  Charging remains independent and correct.
- **Live Console follows the data link.** `live_console.active` is gated by the
  corrected `usb_data.pc_connected`, so one detach clears both icons in the same
  read. The console daemon is never killed to extinguish the icon.
- **Launcher cache `v45-a77-usb-detach`** for the changed indicator script and
  cache-busted icon URLs; `index.html`, the manifest and the service worker
  agree.
- **Release visibility.** The release workflow now publishes the build as the
  repository's **Latest** release (the beta tag/title is unchanged) so the main
  GitHub page no longer points at v0.6.0-beta while newer prereleases exist.
- **Whole-repo lockstep bump to `v0.6.6-beta`** across `VERSION`, device
  `APKBUILD`s, PWA/bridge manifests, services, systemd environment pins, shell
  apps, OTA/VM tooling and docs.

## Release contents

The workflow builds the S10+ BOOT image and Fedora 43 ARM64 phone userspace
from the exact merged commit, runs the source/regression gates, and publishes:

- `nuxel-v0.6.6-beta-s10plus.tar.gz` — CI-built image set from this commit;
- `nuxel-installed-s10plus-boot.img.gz` — the byte-exact BOOT image installed
  on the owner's handset (unchanged by this userspace-only release);
- `nuxel-installed-s10plus-userspace-files.txt.gz` — SHA-256 inventory of the
  installed userspace, refreshed from the phone after the A77 deployment;
- `INSTALLED-IMAGES.json`, `SHA256SUMS.txt` and `RELEASE-NOTES.md`.
