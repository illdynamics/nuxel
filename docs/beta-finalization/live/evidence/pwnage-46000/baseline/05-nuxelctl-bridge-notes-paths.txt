=== nuxelctl help ===
nuxelctl — the Nuxel live-console control tool (A33).

A33 adds the boot-surface controls that have to agree with the Settings UI:
    nuxelctl verbose-boot status|on|off     durable verbose-boot setting (briq-02b)
    nuxelctl verbose-boot animation MODE    boot animation policy: standard|short|off
    nuxelctl verbose-boot verbosity N       boot-log detail: 0 (quiet) .. 3 (debug)
    nuxelctl verbose-boot override          one-time Bixby-hold override status
    nuxelctl handoff status                 single-owner lock + ownership receipt (briq-02a)
    nuxelctl handoff simulate               replayable handoff timing harness
    nuxelctl handoff audit                  audit the artefacts as an operator would

Every path is resolved through NUXEL_ROOT (default /) so the whole tool can be
exercised by the offline harness against a fake root - the same code path the
device uses.

Everything the graphical Nuxel Settings app can configure is configurable here,
through the SAME files and the SAME service channels - there is exactly one
settings system, not a UI path and a console path:

    /etc/nuxel/display/statusbar-safezones.json   status-bar zone editor (mission 9)
    /etc/nuxel/input/buttons.json                 hardware-button mapping (mission 13)

and live actions are delivered over the running services' own control FIFOs
(/run/nuxel-wl-fb.cmd for the display bridge, /run/nuxel-buttons.cmd for the
hardware-button manager), so a console command and a finger tap do the same thing.

Usage:
    nuxelctl status
    nuxelctl statusbar show
    nuxelctl statusbar zones 9,10            # block zones 9 and 10 (current orientation)
    nuxelctl statusbar preset right_camera|center_camera|left_camera|none|custom
    nuxelctl statusbar orientation portrait|landscape_left|landscape_right
    nuxelctl statusbar padding 8
    nuxelctl display off|on|toggle
    nuxelctl orientation status|get|modes|set <mode>|watch [s]
    nuxelctl volume up|down|mute
    nuxelctl buttons list
    nuxelctl buttons set bixby_short open-terminal
    nuxelctl buttons set power_short screen-toggle
    nuxelctl buttons set bixby_short app:org.nuxel.Mail
    nuxelctl action open-terminal|home|search|settings

P3 subsystems (connectivity, time, audio, headphones, buttons) delegate to the
single shipped implementation of each, so there is never a second copy of the
logic:
    nuxelctl wifi status|scan|connect <SSID>|firmware|report|selftest
    nuxelctl time status|verify|rtc|mark|compare|sync|set <ISO8601>|selftest
    nuxelctl audio status|pipeline|capture|tone|ucm-install|selftest
    nuxelctl headphone status|jack|usbc|route|watch|selftest
    nuxelctl buttons fsm|menu|gates        # state machine, menu table, reboot gate
