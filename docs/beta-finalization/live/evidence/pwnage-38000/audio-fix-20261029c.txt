WHAT WAS ACTUALLY BROKEN IN THE UI TEST PATH
--------------------------------------------
The manual pw-play path reached the sink, but Settings' Test Audio did not
produce any samples at all.  dmesg showed no abox_uaif_trigger after the owner
tapped audio-test at 19:45:30, while a direct pw-play immediately produced
abox_uaif_trigger[P](1).

Root cause: hw_providers._pipewire_play() used
  gst-launch-1.0 filesrc ! decodebin ! audioconvert ! audioresample ! volume
  ! pulsesink
and killed it after a 2.5 s bounded window.  On this image pulsesink never
posts EOS and gst-launch/decodebin had not linked before the window closed.
A second multiplier made it worse: Settings sent gain_percent=25, and the sink
volume was 0.20, so the effective level was 0.20 * 0.25 = 0.05 (5%).

FIXES DEPLOYED
--------------
1. services/nuxel-bridge/src/hw_providers.py
   _pipewire_play() now runs
     pw-play --volume <gain> <asset>
   which blocks until EOS (0.36 s cue), exits 0, and is the same player that
   was already proven to open hw:0,1 and advance the ABox.  Detail string is
   now "pw-play completed" (honest: rc=0 is not an audibility claim).
   AudioProvider._ensure_default_sink() selects alsa_output.hw_0_1 by stable
   name before playback/volume, because after a cold boot WirePlumber can
   publish the sink without a default node; pw-play then failed with
   "Translate ID error: '-1' is not a valid ID (returned by
   default-nodes-api)".
   Deployed to /usr/lib/nuxel/nuxel-bridge/hw_providers.py; service restarted.

2. pwa/nuxel-apps/settings/hardware-settings.js
   Test Audio and volume-preview gain_percent 25 -> 100.  The PipeWire sink
   volume (20%) is now the only attenuation, instead of 20% * 25% = 5%.
   Deployed to /usr/share/nuxel/pwa/nuxel-apps/settings/hardware-settings.js.

3. services/nuxel-s10/bin/nuxel-audio-route.sh
   - sets Left/Right PCM Source = ASP (direct path; DSP stays booted/running)
   - sets ABOX Sound Type = 0 (VOICE, the boot default)

     level the default was inaudible)

     verify Left/Right DSP1 Firmware=9

4. tools/s10plus/a45/nuxel-button-manager.c (built on device, deployed)
   Hardware volume keys now call
     wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
     wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-
   instead of the accidental ALSA element "ABOX PCM ext Out Fade Start"
   (range 0..1, which made every press jump 0%/100%).
   Verified live: 20 -> 25 -> 30 -> 35 -> 30 -> 25 -> 20.
   Volume preview cue is throttled to one per 500 ms, stopping the
