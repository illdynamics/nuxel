# v0.5.2 baseline

The baseline is A34 on the Samsung Galaxy S10+ SM-G975F: Fedora 43 aarch64,
Samsung Linux 4.14.253, headless Phoc, WebKitGTK Nuxel Home, and the DECON
framebuffer screencopy bridge. Historical A34 evidence records real finger taps
opening Mail and Calendar. The 2026-10-18 console probe found the USB descriptor
but host sandboxing denied opening `/dev/cu.usbmodem1201`; no new runtime claim
is inferred from that failed probe.
