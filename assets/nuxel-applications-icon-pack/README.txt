Nuxel OS icon PNG pack
======================

71 individual RGBA PNG icons, each on a transparent 128x128 square.
Icons extracted from the provided original spritesheet with the blue grid, HUD numerals and printed app labels omitted.
Source image is JPEG; some compression artifacts may remain at edges.
The one originally empty spritesheet slot is omitted.
Ordering: row-col prefix, left to right, top to bottom.
See manifest.json for identifiers and source bounding rectangles.
