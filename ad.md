**NUXEL FEDORA HOST OVERRIDE — QONQRETE**

QonQrete now runs on a Fedora Linux laptop with the S10+ physically connected and running Nuxel.

The UTM VM is not currently available. Identify the authoritative launcher through the Nuxel repository's VM startup scripts, services, PWA sources, application registry and build configuration. Do not choose a launcher merely because it contains more code.

Use Fedora-native debugging and build tools. Cross-compile or build all target binaries for ARM64 and verify their architecture and runtime dependencies before deployment.

Prioritize touchscreen end-to-end functionality above all optional application development.

Only one agent may own the live USB console or perform device deployments at a time.

Continue autonomously across multiple engineering cycles. Persist progress, tests, failures, hashes and rollback instructions after every subsystem.

Escalate difficult architectural/root-cause problems to InstruQtor and significant security or release-quality reviews to InspeQtor. Keep ordinary implementation with ConstruQtor and verification/triage with Qlarifier.

**Absolutely no device flashing.** Kernel and bootloader-related fixes may only be built and tested offline.

Do not declare success based on compilation, package installation or service status alone. Require actual behavior and evidence. Mark physical tests that cannot be performed autonomously as NEEDS_OWNER_TEST.

Produce the two mandatory final reports, even if some subsystems remain blocked.
