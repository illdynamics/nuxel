## Required route behavior

**Automatic mode** - HDMI audio becomes genuinely available → route to
HDMI. - HDMI audio disappears → route to last valid non-HDMI output,
normally internal speaker. - HDMI returns → route back to HDMI. -
Display present but HDMI audio absent → do not show HDMI as a usable
audio output; explain the unavailable state. - Re-evaluate on service
start, audio-server reconnect and return to Automatic.

**Manual mode** - User selects a real output → activate it and persist
its stable identity. - HDMI hotplug → do not change the user's
selection. - Selected output disappears → safe fallback, clearly shown;
preserve preferred identity as pending. - User selects Automatic →
immediately re-evaluate and apply automatic policy.

## Required Settings UX

list of real available output devices. - Current output and

and mute. - Test sound button using the existing Nuxel sound test

disconnects. - Live refresh without restarting Settings.
